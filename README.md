### my projects

* **We Are On Time & We Are Booked**
  > [See We Are Booked Repo Here](https://github.com/aaron-silverio/WeAreBooked)

  Developed an individual decentralized room-booking application utilizing smart contract escrows on the blockchain (Solidity) to allow students to reserve study rooms, alongside a smart scheduling web application integrating live university bus data (Next.js).

* **Analog Karaoke Mixer**
  > [See Repo Here](https://github.com/aaron-silverio/analog-tone-control-amplifier)

  Designed and physically built a custom analog audio mixer utilizing operational amplifiers.

* **STM32 Custom TFTP Server Bootloader** 

  Internship Project. Designed and engineered a custom TFTP server-based remote bootloader for STM32 M4 microcontrollers to write payload packets into flash memory. Researched and prototyped a remote programming implementation for an ARTY A7 FPGA.

* **CHIP-8 CPU Emulator** 

  Built a full Fetch-Decode-Execute cycle emulator in C++ and CMake. Implemented 35 opcodes to simulate processor architecture, wrote the opcode interpreter, managed memory registers, and built a real-time graphics and input system using SDL2.
